An API lets one program talk to another. With an API key, a program you or a developer write can send your agent messages and read its replies, the same way you do in the browser. If you only talk to your agent yourself, you do not need this page.

There are two types of API keys:

- A **user key**, which you create in your agent's **Settings** under **API key**.
- An **admin key**, which you create under **Admin settings**. Only the agent's administrator can see this.

> [!warning]
> Anyone who has one of your keys can get complete access to your agent. Store them carefully and do not share them with anyone.
