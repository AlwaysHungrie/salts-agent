You can manage your fleets from the **Fleets** tab on the home page, which appears once you have created your first fleet. Each fleet is shown as one row, with its name and the number of agents in it.

## See who is in the fleet

Click **Manage fleet** on the fleet's row to see every agent in the fleet, along with the email address of the user it belongs to.

## Add users

1. Click **+** on the fleet's row.
2. Enter the email addresses of the new users, separated by spaces.
3. Click **Add agents**.

The new agents start with the fleet's current settings. Remember to tell your new users to sign in with the email address you entered for them.

## Change settings for everyone

1. Click **Fleet Settings** on the fleet's row.
2. Change the settings you need. [Choose the fleet's settings](/guide/fleet-settings) explains each one.
3. Click **Save and apply**, then **Apply to all**.

Keep the page open until every agent has been updated. If the page is closed too early, open **Fleet Settings** and save again to update the rest.

> [!warning]
> Saving fleet settings overwrites every agent in the fleet, including settings your users changed themselves, such as the model they picked or the instructions they wrote. We recommend letting your users know before you change fleet settings.

## Change settings for one user

Open **Manage fleet**, find the user's agent and click its settings icon. This lets you change the settings of that one agent, for example to give one user a higher spending limit.

Keep in mind that the next time you save the fleet's settings, this agent will be overwritten like all the others, so you will need to make the change again.

## Remove a user

Open **Manage fleet**, find the user's agent and click its delete button. This deletes the agent along with every conversation, file and memory in it, and cannot be undone. Deleting an agent frees up a place in your account's agent limit.

## Delete the whole fleet

Click the delete button on the fleet's row, then type the fleet's name to confirm. Keep the page open until every agent has been deleted.

> [!warning]
> Deleting a fleet deletes every agent in it, along with all their conversations, files, memories and settings. This cannot be undone.
