Creating a fleet takes two steps. First you say who gets an agent. Then you choose how every agent is set up.

> What to expect:
>
> - You need a business account first. See [Get a fleet account](/guide/fleet-account).
> - Have the email address of every user ready. Each user must sign in to Salts with exactly that address to find their agent.
> - Have your OpenRouter key ready, if the agents will use it.

## 1. Say who gets an agent

On the home page, click **Create a new Agent**.

1. Under **Name**, enter the name every agent in the fleet starts with, for example "Team assistant". Each user can rename their own agent later.
2. Check **Create a fleet of agents**.
3. Under **Fleet name**, enter a name for the whole fleet, for example the name of your team or company. Users see it on their agent, so they know who provides it.
4. Under **User Emails**, enter the email address of every user, separated by spaces. One agent is created for each address.
5. Check the line under the box. It says how many agents will be created, and whether any address is invalid.
6. Click **Next**.

## 2. Choose the settings

The second step is **Meta settings**: the settings every agent in the fleet starts with, and which of them users are allowed to change.

At the very least:

1. Paste your OpenRouter key under **OpenRouter**, if the agents will use it.
2. Set a **Monthly spend limit** under **Limits**, so no single agent can run up a large bill.

Everything else can stay as it is. [Choose the fleet's settings](/guide/fleet-settings) explains every setting and when to lock it.

Click **Create**. Your fleet now shows up in a new **Fleets** tab on the home page.

## 3. Tell your users

There is no invitation email. Tell each user to go to Salts and sign in with the email address you entered for them. Their agent is already on their home page.

You may also want to send them this guide, starting with [Connect your agent to Telegram](/guide/telegram), so they can talk to their agent from their phone.

## Footnotes

1. If a user signs in with a different email address, they will not see their agent. Add their correct address as a new agent from [Manage your fleet](/guide/manage-fleet).
2. Entering the same address twice creates two agents for that user.
3. You can add more users at any time. You do not have to get the list right the first time.
